---
title: Quick start
description: Connect your coding agent to AgentRail through MCP.
---

1. Start your own AgentRail Console using the repository README. Sign in, create a workspace and connect a repository.
2. Build the MCP server with `pnpm --filter @agentrail/mcp build`.
3. Open **Agents** in the Console and create a workspace workflow key. Configure your client's MCP command as `node`, with the absolute server path as its argument. Set `AGENTRAIL_TARGET`, `AGENTRAIL_BIN`, `AGENTRAIL_WORKFLOW_BASE_URL` and `AGENTRAIL_WORKFLOW_API_KEY` using the displayed settings.
4. Index your project with `agentrail context index --target /path/to/project`.
5. Ask your agent to use `workflow_repositories` and `workflow_start`. It can use `context_search` and `context_get` for bounded source context, `workflow_update` for progress and `workflow_check` for a configured local check.
6. Inspect the task in **Work**. Read check receipts and history, then make the human decision to close or reopen it.

Use stable task/event keys when retrying and read the current revision before resuming. A reported pass is not independently verified acceptance evidence. No Jace account or service is required. CLI-native queued work is a separate optional path.
