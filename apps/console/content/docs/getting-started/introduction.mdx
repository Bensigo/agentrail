title: Introduction
description: Your coding agent, an inspectable workflow, and a shared Console.
---

AgentRail supplies project context, durable tasks and workflow visibility to any MCP-compatible coding agent. Your agent implements the work. AgentRail records progress and configured check receipts; a human reviews and closes each task.

The Python CLI and optional native runner remain available. AgentRail runs independently of Jace, which owns Acceptance Contracts and exact-change acceptance evidence in its own repository.
