---
title: Console
description: Tasks, checks, context and workflow history.
---

**Work** shows MCP tasks shared with your coding agents. **Agents** supplies connection settings and workflow keys. Each task retains progress, check reports, a revision and event history. An owner/admin closes or reopens it after review.

**Native runner**, **Runs** and **Review Gates** retain the optional CLI runner's queue and evidence. Wiki, Memory, Costs and Failures provide context and diagnostics. MCP-task costs are currently unrecorded; reported progress does not establish independent verification.
